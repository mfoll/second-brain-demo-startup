# Version 3 Release Notes

Customer-facing release notes for Quaylane 3.0, published on 2026-09-15 and emailed to all accounts.

## Summary

- **Waitlist autofill**: turn it on in settings; Quaylane offers cancelled slots by SMS to the first matching person on your waitlist and you confirm with one click.
- **Multi-location calendars**: one calendar across your sites, with rooms and rosters per site and appointment moves between sites.
- **Single sign-on** for enterprise plans, live for the first customer since June.

## Why It Matters

The notes set expectations that support then had to meet. The wording on waitlist ("first matching person") came from the matching decision in [[how-should-the-waitlist-pick-the-next-patient]] and saved explanations later.

## Key Details

- Release 3.0.0 tagged in all three application repositories.
- Notes written by Imani's team from the engineering draft.
- Patch notes 3.0.1 to 3.0.4 followed by 2026-10-20.

## Caveats

Written for customers; technical detail is in the GitHub releases.
