# Vibe coding

Wikipedia article, last edited 2026-10-16.

## Summary

Vibe coding is AI-assisted development in which the developer describes the task in natural language and a large language model generates the code. It may involve accepting generated code without thorough review and steering by results and follow-up prompts.

## Why It Matters

The practice our [[ai-coding-tools-policy-draft]] is written to exclude on production code. Accepting code without review is incompatible with the one-approval rule and with how we read change management. Fine for a throwaway prototype on a laptop; not fine in the four production repositories.
