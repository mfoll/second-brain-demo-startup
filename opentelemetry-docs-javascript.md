# OpenTelemetry JavaScript

## Summary

The OpenTelemetry documentation landing page for JavaScript (Node.js and the browser). Its status table lists traces and metrics as stable and logs as in development, and it warns that client instrumentation for the browser is experimental and mostly unspecified.

## Why It Matters

Re-read while preparing the restart of the [[observability-overhaul]] for 2027-Q1. Stable traces and metrics on Node.js cover the API and workers; the browser warning is why front-end tracing stays out of scope.

## Caveats

Status changes with releases; check again before restarting.
