# OWASP Application Security Verification Standard

Overview page of the OWASP Application Security Verification Standard (ASVS). The latest stable release listed is ASVS 5.0.0, published 2025-05-30.

## Summary

ASVS is a framework of security requirements for designing, building and testing web applications and web services. It is meant as a basis for testing security controls, a list of secure development requirements for developers, a yardstick for how far an application can be trusted, and a basis for security requirements in procurement contracts.

## Why It Matters

Two uses for Quaylane. First, a structured self-assessment of the web app in 2027 ([[security-roadmap-2027]]), starting with authentication and access control, which is where tenant boundaries live. Second, enterprise questionnaires increasingly reference it; answering "we self-assess against ASVS 5.0" with evidence is stronger than a list of practices. [[min-jae-oh]] suggested it after the SSO work.

## Caveats

The overview page does not describe the verification levels; read the standard itself before scoping. A self-assessment is not an independent test.
