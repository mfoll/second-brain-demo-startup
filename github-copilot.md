# GitHub Copilot

Wikipedia article, last edited 2026-10-14.

## Summary

GitHub Copilot is a code completion and programming assistant from GitHub that works inside common editors and IDEs, sold by subscription to individuals and businesses. It was first announced on 29 June 2021, and users can choose which large language model generates the suggestions.

## Why It Matters

The tool we used in the 2026-08 to 2026-09 pilot ([[ai-assistant-pilot-results-2026-09]]), on business accounts only. Model choice per user is a policy question for the [[ai-coding-tools-policy-draft]]: the vendor agreement has to cover whichever model is selected.

## Caveats

Product details change quickly; check the vendor's own terms before the policy is adopted.
